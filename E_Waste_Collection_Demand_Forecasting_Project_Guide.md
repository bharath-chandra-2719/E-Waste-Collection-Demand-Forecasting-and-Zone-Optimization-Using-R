# E-Waste Collection Demand Forecasting and Zone Optimization Using R

## 1. Introduction

Electronic waste (e-waste) includes discarded electronic items such as mobile phones, computers, televisions, chargers, and household appliances. When these items are not collected and recycled properly, recoverable materials may be wasted and harmful components may be handled unsafely. Efficient collection planning requires an understanding of e-waste trends and the needs of different local areas.

This project analyses historical e-waste generation and recycling data for India, compares two forecasting methods, and groups Hyderabad municipal wards into three preliminary collection zones using population and household counts. It is implemented in **R** using Google Colab-style file paths.

The project has two main parts:
1. **Forecasting:** studies annual e-waste generation and recycling, then compares ARIMA and Random Forest predictions.
2. **Zone grouping:** uses ward population and household data with K-Means clustering to group wards with similar demographic characteristics.

The results are intended to support initial planning. The notebook does not directly measure e-waste generated by each ward or calculate collection routes.

## 2. Aim and Objectives

**Aim:** To analyse e-waste trends, compare forecasting models, and explore demographic-based collection zones using R.

**Objectives:**
- Clean and analyse generation and recycling data.
- Calculate yearly recycling percentages and visualize trends.
- Forecast the next two annual values using ARIMA.
- Compare ARIMA and Random Forest using MAE, RMSE, and MAPE.
- Examine a separate, more recent e-waste dataset.
- Group 108 wards into three clusters using population and household counts.
- Save charts and summary tables for project reporting.

### 7.3 Compare predictions and error metrics

The test years are 2023 and 2024. The notebook compares actual quantities with model predictions and calculates three metrics:

- **MAE:** average absolute prediction error; lower is better.
- **RMSE:** square root of the average squared prediction error; lower is better and large errors are penalized more.
- **MAPE:** average absolute percentage error; lower is better when actual values are non-zero.

### 8.2 K-Means clustering

Before clustering, the notebook standardizes population and household counts so that differences in scale do not dominate the distance calculation. It fixes the random seed and creates three clusters:

```r

zone_scaled <- scale(zone_features)
set.seed(123)
kmeans_model <- kmeans(zone_scaled, centers = 3, nstart = 25)
```

Each ward receives a label: Zone 1, Zone 2, or Zone 3. The notebook then produces a ward-to-zone table and charts comparing the zones by population and households.
